# Before You Go — Problem Definition

## 원문 보존 상태

요청에서 언급한 **11개 섹션의 문제 정의 원문은 현재 저장소 및 로컬 Git 이력에 없다.** 이 문서는 그 원문을 복원하거나 대신 작성한 문서가 아니다. 원문이 제공되면 요약·삭제하지 않고 보존해야 한다.

원문에서 보존해야 할 섹션: 문제의 출발점 / 실제 국민연금 사례 / 사용자 인터뷰 / 공식 행정 절차의 복잡성 / 문제의 본질 / 해결 방향 / 기존 서비스와의 차별성 / MCP가 필요한 이유 / MVP 범위 / 확장 가능성 / 최종 문제 정의와 발표 메시지.

## 이번 요청에서 제공된 문제 배경

아래는 사용자가 이번 작업에서 제공한 설명의 기록이다. 별도로 인터뷰 원본이나 행정 자료를 검증한 결과가 아니다.

행정 서비스는 디지털화되고 있지만, 자신의 상황에 맞는 처리 절차를 찾아 실행하는 과정은 여전히 복잡하다. 같은 업무라도 신청 자격·신청 주체·가입 유형·담당 기관에 따라 경로가 달라지고, 여러 안내 문서를 사용자가 직접 검색하고 대조해야 한다. 한 경로가 막히면 다른 가능한 경로를 다시 찾아야 한다.

사용자가 제공한 실제 사례에서는 국민연금 보험료 변경을 위해 고객센터에 전화했으나 연결이 어려웠고, 연결 후 신청 주체 관련 조건을 추가 안내받아 재시도가 필요했다. 이는 특정 신청 주체의 법적 권한이나 전화 외 경로의 존재를 입증하는 근거가 아니다.

사용자가 전달한 인터뷰 요구:

> 전화 연결이 안 되더라도, 다른 방법으로 처리할 수 있는 가이드를 찾아서 알려주면 좋겠다.

따라서 핵심 가치는 신청 가능 여부만 검사하는 것이 아니라, 사용자의 상황을 확인하고 현재 방법이 막혔을 때 **공식적으로 확인된 다른 경로와 다음 행동**을 안내하는 것이다. 대안의 존재만으로 이용 가능성을 단정하지 않으며 확인되지 않은 부분은 질문과 불확실성으로 드러낸다.

## 비전과 발표 메시지

“행정 절차를 바꾸지 않아도, 그 절차를 찾아 헤매는 경험은 바꿀 수 있다.”

사용자가 실제 행동 전에 자신의 상황에 적용되는 절차와 준비 사항을 공식 근거로 확인하도록 돕는다. 단순 검색·요약을 넘어 상황과 절차를 대조하고, 막힌 경로에서 다음 행동을 찾는 경험을 개선한다.

현재 MVP는 국민연금 임의가입자의 보험료 변경에 제한한다. 다른 가입 유형이나 보험·민원 업무로의 확장은 공식 근거와 필요성이 확인된 이후의 검토 대상이다. 이 문서에는 코드 구조를 넣지 않는다. 현재 제품 범위는 [brief.md](brief.md), 기술 계약과 구현 상태는 [tool-contract.md](tool-contract.md) 및 [architecture.md](architecture.md)를 따른다.
